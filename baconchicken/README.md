# Bacon and Chicken - Farmer's Delight addon (Forge 1.20.1)

Build on GitHub: push this repo, open the Actions tab, download the `baconchicken-jar` artifact.
Build locally: gradle build   (JDK 17 + Gradle 8.1.1)
Jar:    build/libs/baconchicken-1.20.1-1.0.0.jar  -> put in /mods next to Farmer's Delight

Recipe (crafting table):
  Cooked Chicken | empty | Cooked Bacon   (x3 rows)

Eating it: full health, full hunger, Regeneration II (30s), Strength II (30s).
